# 病历自动抽取工具

Windows 本地桌面工具。源 Excel 始终只读，结果写入新的工作簿。

## 使用

1. 双击 `病历自动抽取工具.exe`。
2. 添加一个或多个 `.xlsx` 文件，或选择文件夹批量加入其中的 `.xlsx` 文件。
3. 按 `YYYY-MM-DD` 设置检查开始日和结束日（均包含）；成功开始抽取后，程序会记住该时间段供下次启动使用。
4. 设置每文件抽取条数和随机种子，选择输出目录后开始抽取。

同一随机种子可复现同一批结果。输出保留完整姓名和其他业务字段，但完全移除人员/个人编号及身份证/证件号列。

## 开发运行

```powershell
python app.py
python -m pytest -q
```
