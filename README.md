# 病历自动抽取工具

Windows 本地桌面工具。源 Excel 始终只读，结果写入新的工作簿。

## 使用

1. 双击 `病历自动抽取工具.exe`。
2. 添加一个或多个 `.xlsx` 文件，或选择文件夹批量加入其中的 `.xlsx` 文件。
3. 选择抽取方式：
   - `按年份随机抽取`：按 `YYYY-MM-DD` 设置检查日期范围，再设置每文件抽取条数和随机种子。
   - `按科室基金支付总金额前十`：在检查日期范围内，按每个科室的基金支付总额从高到低抽取前 10 份病历；该方式不使用“每文件条数”和随机种子。
4. 选择输出目录后开始抽取。程序会记住检查时间段、输入/输出目录和抽取方式，供下次启动使用。

同一随机种子可复现同一批结果。输出保留完整姓名和其他业务字段，但完全移除人员/个人编号及身份证/证件号列。

## 按科室金额排名的 Excel 要求

可直接使用需求 SQL 导出的 `.xlsx` 文件。程序会自动识别表头，必需字段为：

- `开始时间`（或入院时间）或 `结算时间`
- `就诊ID`
- `人员姓名`
- `科室名称`
- `基金支付总额`

同一就诊因诊断列表等关联数据出现多行时，会先合并为一份病历再排名。基金支付总额支持 Excel 数值以及带千位分隔符的文本数值。科室为空或基金支付总额无法解析的病历不参加排名；金额相同时按源 Excel 中首次出现的行号排序。

## 开发运行

```powershell
python app.py
python -m pytest -q
```

命令行可通过 `--mode "按科室基金支付总金额前十"` 选择新抽取方式。
